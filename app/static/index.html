Im Steam-Profil muss unter Privatsphäre „Spieldetails“ auf öffentlich stehen, sonst sind die Erfolge nicht abrufbar.

Bei playstation.com anmelden, dann ca.account.sony.com/api/v1/ssocookie öffnen und den Wert von npsso hier einfügen. Läuft nach ca. 2 Monaten ab.

Cover

Platzhalter: {appid} (Steam-AppID bzw. Plattform-ID), {title}, {title_raw}, {slug}, {title_underscore}, {platform}. Fehlt ein Bild, wird automatisch auf das offizielle Cover zurückgegriffen.

Spielhülle

Steam-Spiele bekommen die Steam-Hülle, PlayStation-, Xbox- und Nintendo-Spiele die passende Konsolen-Hülle (nach Konsole, z.B. PS4/PS5). Die Hüllen-Grafiken stammen aus steam-case-covers (GPL-3.0) und werden beim ersten Gebrauch von GitHub geladen.

Bild fürs Steam-Profil

PNG herunterladen
So kommt das Bild ins Steam-Profil
  1. Steam im Browser öffnen (nicht im Steam-Programm) → dein Profil → Artwork → Artwork hochladen.
  2. Datei wählen. Ist das Bild höher als breit, vor dem Hochladen in der Browser-Konsole (F12) eingeben:
    $J('#image_width').val('1000');$J('#image_height').val('1');
    Sonst schneidet Steam die Vorschau falsch zu.
  3. Sichtbarkeit auf Öffentlich, Haken bei der Urheberschaft setzen, speichern.
  4. Profil bearbeiten → Vitrine → beim 630-px-Bild „Featured Artwork Showcase“, beim 506-px-Bild die normale „Artwork Showcase“ wählen und das hochgeladene Bild zuweisen.

Vitrinen gibt's ab Steam-Level 10. Cover gehören den jeweiligen Publishern – fürs eigene Profil ist das üblich, verkaufen solltest du das Bild nicht.
